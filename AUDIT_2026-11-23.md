## Temuan terverifikasi
1. **Secrets (sedang / perlu verifikasi produksi):** Tidak ditemukan file `.env` atau kunci nyata pada file di branch utama yang diperiksa. `.env.example` memuat nama variabel dengan nilai kosong, dan `.gitignore` mengecualikan `.env*` selain `.env.example`. Ini **tidak membuktikan** bahwa secret tidak pernah bocor di platform, log deployment, atau tempat lain. Jangan mengisi `.env.example` dengan nilai rahasia.
2. **Akses admin dan database (tinggi / fungsi belum dibangun):** Belum ada login admin, middleware otorisasi server, koneksi DB, kebijakan RLS, atau alur pembayaran di repo ini. Oleh sebab itu keamanan admin/member/keuangan pada website aktif belum dapat dinilai dari source ini.
3. **Pendaftaran event (sedang / diperbaiki di branch):** Tautan REGIST sebelumnya mengarah ke nomor WhatsApp placeholder `6280000000000`, dan event lama masih dapat tampil sebagai pendaftaran terbuka. Sekarang tautan invalid tidak ditampilkan; status event memakai tanggal penutupan di zona WITA. Saat belum ada tautan yang sah, muncul keterangan tanpa link.
4. **Navigasi mobile (sedang / diperbaiki di branch):** CSS sebelumnya menyembunyikan menu pada layar kecil, kartu event tetap 3 kolom sempit. Sekarang menu bisa digeser horizontal dan kartu menjadi 2/1 kolom sesuai lebar layar.
5. **Header keamanan (rendah / ditingkatkan):** Sudah ada `nosniff` dan Referrer-Policy; kini ditambahkan `X-Frame-Options: SAMEORIGIN` dan Permissions-Policy untuk geolocation/microphone.
