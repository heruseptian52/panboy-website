## Keamanan dan batas audit

- Scan snapshot untuk file environment, private key, token provider berformat umum, serta dump. Yang disertakan hanya `.env.example` dengan nilai kosong. Jalur sumber dan hasil scan tidak membuktikan bahwa histori penuh atau runtime bebas kebocoran.
- Next.js, React/React DOM, React Server Components, dan fflate diperbarui. `npm audit --omit=dev` mencatat 0 temuan untuk klasifikasi paket produksi. Audit lockfile lengkap masih mencatat 15 temuan di perangkat build/preview, termasuk Vinext/Vite/Cloudflare. Vinext ikut membangun Worker, sehingga hasil audit produksi saja tidak menghapus risiko tersebut. Uji pembaruan perangkat build di branch tersendiri sebelum publikasi.
- Bukti yang pernah dilihat atau tersimpan di cache sebelum perbaikan berada di luar verifikasi. R2 produksi, WAF/rate limit, keaslian header bootstrap pada proxy tujuan, serta callback dan credential merchant belum diperiksa melalui akses hosting.
- Pengujian perubahan peran, callback iPaymu, pembayaran QRIS, dan sinkronisasi Drive secara end to end membutuhkan staging D1/R2 terisolasi, akun admin uji yang dikonfigurasi melalui staging, serta secret sandbox dari pengelola layanan. Jangan kirim password atau API key melalui chat.
- Hasil ini belum diterapkan ke production. Pengujian desktop/HP pada perangkat nyata, pengukuran performa produksi, dan pengecekan transaksi asli masih terbuka.
